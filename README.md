# Test Site - Tek Kişilik Özel Bulut Sunucusu

Bu proje 0 maliyetle çalışan ve sadece 1 kişinin erişimine izin veren güvenli kişisel web sunucusudur.

## Özellikler
- **0 TL Maliyet**: Render, Vercel veya Glitch üzerinde ücretsiz çalışır.
- **Tek Kişilik Erişim Kilidi**: Sadece doğru şifreyi bilen 1 aktif oturum kabul edilir.
- **Kişisel Notlar ve Görevler**: Şifreli kişisel kontrol paneli.
- **Canlı Sunucu İstatistikleri**: RAM ve Uptime takibi.

## Başlatma
```bash
npm start
```
